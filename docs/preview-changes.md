# 미리보기에서 바뀐 것 (휴먼터치 보강)

> **한눈에** 보내 주신 휴먼터치 보강본을 실제 허브와 같은 사이트 사본에 반영했습니다. 바뀐 문서는 [화법·반론처리·휴먼터치 모음](#d220ba5d7) 하나이고, 문서 위 «휴먼터치» 버튼을 누르면 바로 내려갑니다. 실제 허브는 아직 그대로입니다.

## 1. 보내 주신 내용이 들어간 곳

| 보내 주신 내용 | 미리보기 문서 안 위치 |
|---|---|
| 대표님 성향부터 (결론형·공감형·분석형, 파악하는 법) | 휴먼터치 › 1 |
| 휴먼터치 원칙 5 | 휴먼터치 › 2 |
| 미팅 전 관찰 준비 | 휴먼터치 › 3 |
| 단계별 휴먼터치 (01 ~ 소개요청) | 휴먼터치 › 4 |
| 대표님 성향별 대응 | 휴먼터치 › 5 |
| 미팅이 예상과 다르게 흘러갈 때 | 휴먼터치 › 6 |
| "그거 보험 아니에요?"라고 물으면 | 휴먼터치 › 7 |
| 듣는 기술 / 침묵과 몸짓 / 분위기 읽기 | 휴먼터치 › 8 · 9 · 10 |
| 미팅 뒤 휴먼터치 | 휴먼터치 › 11 |
| 하지 말 것 | 휴먼터치 › 12 |
| 내 경험 채우기 | 휴먼터치 › 13 (함께 만들기로 보내 달라는 안내로) |
| 꼭 확인할 것 14개 | 맨 아래 «꼭 확인할 것»에 원래 5개와 합침 |

## 2. 맞추면서 바꾼 것

| 무엇을 | 어떻게 | 이유 |
|---|---|---|
| 원래 «휴먼터치 팁» 5줄 | 지우지 않고 새 표 안에 녹임 (예: "하나만 있으면 아부이거나 건방집니다") | 원래 내용이 빠지지 않게 |
| "가만히 있으면 14억, 준비하면 6억" | "14.2억 / 5.8억" | 같은 문서 위쪽 숫자와 맞춤 |
| 현장 메모 표시 | 이름 없이 «현장 메모»로 | 공개 허브는 사람 이름을 쓰지 않는 규칙 |
| 빈 «내 경험 채우기» 표 | 함께 만들기로 보내 달라는 한 줄로 | 빈 표가 공개 사이트에서 미완성처럼 보여서 |
| 오프닝·반론·클로징·금지어 | 그대로 | 보강본의 «바꾸지 않은 것»과 같음 |

## 3. 확인 부탁드릴 것

- [ ] 보내 주신 뜻과 다르게 바뀐 문장이 없는지
- [ ] 더 넣고 싶거나 빼고 싶은 부분
- [ ] 예시 멘트 중 현장에서 다르게 쓰시는 표현
