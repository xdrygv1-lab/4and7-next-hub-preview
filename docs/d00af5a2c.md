# 휴먼터치 보강 변경점

> 대상 원본: 허브 › 공부하기 › 첫 미팅 화법 › "화법·반론처리·휴먼터치 모음"
> 보강본: 휴먼터치 보강본
> 이 문서는 현장 메모 부분(보강본 0절, 4-1절, 4-2절, 결론형·공감형·분석형 3분류)을 **빼고** 정리했습니다.

**한눈에** 원본의 휴먼터치 팁 5줄을 10개 섹션으로 넓혔습니다. 원본이 *무엇을* 말할지 정리했다면, 보강본은 *어떻게* 말하고 *무엇을 피할지*를 더했습니다. 컨셉별 첫마디·질문 세트·반론 대응·클로징 멘트는 원본 그대로 둡니다.

## 1. 원본 "휴먼터치 팁" 5줄 → 보강본

| 원본 (A) | 보강본 (B) | 보강본 위치 |
|---|---|---|
| 칭찬과 공통점을 같이 | 칭찬은 **구체적으로**, 공통점은 **작게**. 예시 멘트와 피할 말 추가 | 3절 02단계 |
| 기존 보험은 "어떻게 가입하셨는지" 묻기 | 예시 멘트("지금 보험은 어떻게 가입하시게 됐어요?")와 피할 말(기존 보험 깎아내리기) 추가 | 3절 14 F.F |
| 가족 이야기로 감성 터치 | 세 곳으로 나눔: ① 가족 질문은 **예고 → 허락 → 질문** ② 대답에 감정이 실리면 한 번 더 묻기 ③ 표정이 굳으면 바로 멈추고 다른 주제로 유연하게 | 3절 14 F.F / 3절 08 / 7절 |
| 핵심 숫자 뒤 3초 침묵 | 침묵하는 순간 3가지(핵심 숫자 뒤, 클로징 질문 뒤, 대표님이 생각에 잠겼을 때) + 앉는 자리, 시선, 휴대폰 | 6절 |
| 도장 후 첫 출금 전까지 케어 | 6개 시점별 연락: 당일 감사 문자 → 다음 미팅 전날 → 첫 출금 전 → 1개월 → 분기 → 기념일. 문자 예시 포함. "소개는 사후관리에서 만족한 시점에 더 잘 나온다" 추가 | 8절 |

## 2. 원본의 다른 부분에서 넓힌 것

| 원본 (A) | 보강본 (B) | 보강본 위치 |
|---|---|---|
| 릴렉스: "오면서 본 것" 한 줄 | 전날·오는 길·사무실 입구·대표실에서 무엇을 보고 어떻게 말할지 표로. "관찰한 건 칭찬 한 번에 쓰고 끝내기" 주의 추가 | 2절 |
| AP 15단계 표: 단계별 멘트와 체크포인트 | 같은 15단계(허브 순서: 01~11 → 14 → 12 → 13 → 15 → 소개요청)에 휴먼터치 포인트·예시 멘트·피할 것 | 3절 |
| 금지어 표 | 7가지 추가: 관찰한 것 늘어놓기, 말 끊고 내 이야기, 예고 없는 가족 질문, 사고·사망 길게 묘사, 다른 고객 이야기, 과한 친근함, 계약 때만 연락. 원본 금지어는 그대로 | 9절 |

## 3. 원본에 없던 것 (새로 만듦)

| 원본 (A) | 보강본 (B) | 보강본 위치 |
|---|---|---|
| 없음 | 휴먼터치 원칙 5: 듣는 시간 > 말하는 시간, 숫자는 머리로 결정은 마음으로, 대표님 단어로 되돌려주기, 불편한 질문은 예고하고 허락받기, 계약 뒤가 진짜 시작 | 1절 |
| 없음 | 대표님 성향별 대응: 숫자형, 경계형, 승계 앞둔 2세 대표, 결정자가 여럿 | 4절 |
| 없음 | 듣는 기술: 되묻기, 요약하기, 감정에 이름 붙이기, 손으로 메모하기, 짧은 맞장구 | 5절 |
| 없음 | 분위기 읽기: 신호 6가지와 대응 (아래 표) | 7절 |
| 없음 | 내 경험 채우기 사례 칸 (상황 / 내가 한 말 / 반응 / 결과) | 10절 |
| 없음 | 꼭 확인할 것 체크리스트 | 맨 끝 |

**7절 분위기 읽기**

| 신호 | 대응 |
|---|---|
| 몸을 앞으로 기울임, 질문을 함 | 속도를 늦추고 충분히 답하기 |
| 대표님이 자기 숫자를 먼저 말함 | 받아 적고 그 숫자로 계산해 보여주기 |
| "그건 얼마나 들어요?" | AP에서는 답하지 않고 다음 약속으로 연결 |
| 시계·휴대폰을 봄 | 결론으로 건너뛰고 다음 약속 잡기 |
| 대답이 짧아짐, 팔짱 | 질문 세례를 멈추고, 대표님이 원하시는 부분이나 궁금하신 부분이 있으신지 확인하기 |
| 가족 이야기에 표정이 굳음 | 바로 멈추고 다른 주제로 유연하게 넘어가기 |

## 4. 바꾸지 않은 것

- 오프닝·포지셔닝 멘트
- 컨셉별 첫 마디
- 숫자를 받아내는 질문 세트, F.F 전환
- 반론처리 공식, 반론별 대응
- 제안·클로징·소개 멘트
- 원본 금지어 표

## 5. 검토 요청

- 보강본의 예시 멘트는 초안이라 현장 검증이 필요합니다.
- 허브 원칙(AP 상품명·구조 언급 금지, 세무 처리는 세무사 검토 사항, 고객 실명 금지)에 어긋나는 내용이 없는지 확인 부탁드립니다.
